# Pup

Pup is Schematic's command-line tool for checking software behavior.
It finds supertests in C, Rust, and Python, sends source to Schematic for checking,
and displays results and proposed fixes.

[Read the Pup documentation](https://docs.schematic.tech/pup/).

## Install

```sh
curl -fsSL https://get.schematic.tech/pup.sh | sh
```
